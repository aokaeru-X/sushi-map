## 3行でいうと

- 中国全土の書道史跡・碑刻・博物館 **55件** を地図上にまとめた、**日本語話者の個人旅行者向け**ガイドサイトです。
- **ビルド不要の静的サイト**（HTML + CSS + 素のJavaScript + JSON）。サーバーもデータベースもフレームワークも使いません。
- 編集作業のほとんどは **`data/` 配下のJSONを直すだけ** で完結します。

## 最初にこれだけやってみる

```bash
git clone https://github.com/aokaeru-X/sushi-map.git
cd sushi-map
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

これで動きます。インストール作業は一切ありません。

## 用語のミニ辞典

コード・データに出てくる言葉です。書道の専門用語は分からなくても作業できますが、意味を知っておくとデータの意図が読めます。

| 用語 | 読み | 意味 |
| --- | --- | --- |
| 碑（碑刻） | ひ（ひこく） | 文字を刻んだ石。書道史の一次資料 |
| 摩崖 | まがい | 自然の岩壁に直接刻んだ文字 |
| 拓本 | たくほん | 碑の表面に紙を当てて写し取ったもの |
| 法帖 | ほうじょう | 名筆を石や木に刻んで複製し、手本にしたもの |
| 簡牘 | かんとく | 竹や木の札に書かれた文書。肉筆が残る貴重な資料 |
| 甲骨文 | こうこつぶん | 亀甲・獣骨に刻まれた最古の体系的漢字 |
| 金文 | きんぶん | 青銅器に鋳込まれた文字 |
| 名跡 | めいせき | 有名な書の作品 |
| 石窟 | せっくつ | 岩山を掘った寺院。壁面に造像記（仏像を作った由来の刻文）が残る |
