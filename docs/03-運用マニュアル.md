# 03. 運用マニュアル

実際の作業手順です。**上から順にコマンドをそのまま実行すれば動きます。**

## 0. 必要なもの

| | 用途 | 確認コマンド |
| --- | --- | --- |
| Git | ソースの取得・更新 | `git --version` |
| Python 3 | ローカルサーバー・データ点検 | `python3 --version` |
| Node.js 18+ | 台北故宮 Open Data の取込（使うときだけ） | `node --version` |
| ブラウザ | 動作確認 | — |

**インストールが必要なパッケージはありません。** `npm install` も `pip install` も不要です。

---

## 1. サイトをローカルで動かす

```bash
git clone https://github.com/aokaeru-X/sushi-map.git
cd sushi-map
python3 -m http.server 8000
```

ブラウザで開く：

- http://localhost:8000/ → 書の旅（トップ）
- http://localhost:8000/sushi.html → 蘇軾足跡地図

終了は `Ctrl + C`。

> **`index.html` をダブルクリックで直接開かないでください。** `file://` ではブラウザのセキュリティ制限で JSON の読み込みがブロックされ、地図にピンが出ません。必ず上のサーバー経由で開きます。

## 2. データを編集する（いちばん多い作業）

### 手順

```bash
# 1. 最新を取得して作業ブランチを作る
git checkout main
git pull origin main
git checkout -b edit/開館時間の更新     # 分かりやすい名前を付ける

# 2. データを編集
#    data/calligraphy-sites.json  … 史跡・博物館
#    data/calligraphy-index.json  … 索引
#    （書き方は 02-データ仕様.md を参照）

# 3. 【必須】構文チェック
python3 -m json.tool data/calligraphy-sites.json > /dev/null && echo "sites OK"
python3 -m json.tool data/calligraphy-index.json > /dev/null && echo "index OK"

# 4. 【必須】ブラウザで目視確認
python3 -m http.server 8000
#    → 編集した項目のピンが出るか、詳細パネルが崩れていないか

# 5. コミットして push
git add data/
git status                      # ← .env や余計なファイルが混ざっていないか必ず見る
git commit -m "西安碑林博物館の入場料を2025年改定に更新"
git push -u origin edit/開館時間の更新

# 6. GitHub で Pull Request を作成 → レビュー → main へマージ
#    main にマージされると数分で公開サイトに反映されます
```

### やってはいけないこと

- ❌ `main` ブランチで直接編集・push する
- ❌ 構文チェックをせずに push する（**サイト全体が真っ白になります**）
- ❌ `id` フィールドを変更する（索引からの参照が切れます）
- ❌ APIキーやパスワードを含むファイルをコミットする

## 3. 機能を変更する（HTML/CSS/JS）

| 変えたいもの | 触るファイル |
| --- | --- |
| 詳細パネルの表示項目・順序 | `js/calligraphy.js` の `renderSiteDetail()` |
| 地図のピンの見た目 | `js/calligraphy.js` の `numberedIcon()` ／ `css/calligraphy.css` |
| カテゴリの追加・色変更 | `js/calligraphy.js` 冒頭の `CATEGORY_COLORS` と `CATEGORY_ORDER` |
| サイドバーの構成 | `index.html` と `js/calligraphy.js` |
| 全体の配色・フォント | `css/style.css` の `:root` 変数 |

**変更時の鉄則：**

1. **データを画面に出すときは必ず `escapeHtml()` を通す。** 例外を作らないでください。
2. ブラウザの開発者ツール（F12）のコンソールを開き、**エラーが0件であること**を確認する。
3. 画面幅を狭めて**スマートフォン表示**も確認する（現地でスマホから使うため）。

## 4. 台北故宮 Open Data を更新する

`data/npm-collection.json` を再生成します。3つのモードがあります。

### モードA：OpenAPI から取得（APIキーが必要）

```bash
# キーは https://openapiweb.npm.gov.tw/ で申請する
cp .env.example .env
# .env を開いて NPM_API_KEY と NPM_API_PATH を記入（.env はコミットされない）

NPM_API_KEY=あなたのキー NPM_API_PATH=/利用するAPIのパス \
  node scripts/fetch-npm-opendata.mjs --mode=api
```

### モードB：ダウンロードしたデータセットから取り込む（**キー不要・おすすめ**）

```bash
# https://theme.npm.edu.tw/opendata/ の「文物查詢下載」からXML/JSONを入手
node scripts/fetch-npm-opendata.mjs --mode=file --input=./npm-dataset.xml
```

### モードC：通信せずシードだけ生成

```bash
node scripts/fetch-npm-opendata.mjs --mode=validate
```

### 実行後

```
  ✓ 快雪時晴帖        ← 照合できた
  · 書譜              ← 照合できず（参照リンクのみ）

書き出し: data/npm-collection.json（照合済 3/10 件）
```

`✓` が付いた作品は画像・文物統一編號・ライセンスが入ります。`·` の作品は画面上で「Open Data未照合」と表示されます。

> **画像ライセンス**：低解像度（100万画素）は CC0、中解像度（600万画素）は CC BY 4.0 です。CC BY の画像を使う場合は「國立故宮博物院」の出所表示が必要で、画面には常時表示しています。

## 5. 公開する（GitHub Pages）

### 5.1 現在の公開設定

| 項目 | 設定値 |
| --- | --- |
| リポジトリ | https://github.com/aokaeru-X/sushi-map （public） |
| 配信元 | `main` ブランチ / `(root)` |
| 公開URL | https://aokaeru-x.github.io/sushi-map/ |

### 5.2 通常の更新（設定変更は不要）

**`main` にマージするだけで自動的に公開されます。** 反映まで1〜2分。ビルド作業は要りません。

### 5.3 初回セットアップ（すでに完了している場合は不要）

1. **Settings → General → Default branch** を `main` に設定
2. **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)` → **Save**
3. 1〜2分待って https://aokaeru-x.github.io/sushi-map/ を開く

### 5.4 公開前チェックリスト

```bash
# 秘密情報が混ざっていないか
git ls-files | grep -iE '\.env$|\.key$|secret|credential' && echo "!! 要確認" || echo "OK"

# JSONが壊れていないか
python3 -m json.tool data/calligraphy-sites.json > /dev/null && \
python3 -m json.tool data/calligraphy-index.json > /dev/null && echo "JSON OK"
```

- [ ] 上記2つのチェックが通る
- [ ] ローカルで両ページが正常表示される
- [ ] ブラウザのコンソールにエラーが出ていない
- [ ] スマートフォン幅でも崩れていない

## 6. トラブルシューティング

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| **地図にピンが1つも出ない** | `file://` で開いている | `python3 -m http.server 8000` 経由で開く |
| **サイドバーに「データの読み込みに失敗しました」** | JSONの構文エラー | `python3 -m json.tool data/calligraphy-sites.json` でエラー箇所を特定 |
| **地図の背景が灰色のまま** | ネット未接続／OpenStreetMapに到達できない | 接続を確認。ピンやパネルが出ていれば本体は正常 |
| **追加した項目が地図に出ない** | `category` が規定外の値／座標が範囲外 | [02-データ仕様 1.3](02-データ仕様.md#13-category-に使える値) の6種のいずれかにする |
| **索引をクリックしても飛ばない** | `relatedSiteId` が存在しないIDを指している | [02-データ仕様 5](02-データ仕様.md#5-編集後の確認手順) の③で検出できる |
| **故宮の所蔵品欄が出ない** | `data/npm-collection.json` が無い/壊れている | 仕様上の想定内。必要なら[4節](#4-台北故宮-open-data-を更新する)で再生成 |
| **公開サイトに変更が反映されない** | `main` にマージされていない／反映待ち | PRのマージ状況を確認。2〜3分待つ。ブラウザのキャッシュを消す（Ctrl+F5） |
| **中国語住所が文字化けする** | ファイルがUTF-8で保存されていない | エディタの文字コード設定をUTF-8にして保存し直す |

## 7. 定期的にやるとよいこと

このサイトは**現地の運用情報**を多く含むため、放置すると古くなります。

| 頻度 | 作業 |
| --- | --- |
| 半年〜1年ごと | 主要館（故宮・国博・上博・西安碑林など）の**開館時間・料金・予約要否**を公式サイトで確認して更新 |
| 半年〜1年ごと | `sources` と `digitalResources` の**リンク切れ点検** |
| 随時 | 新しい発掘・新館開館などがあれば `latestFindings` を更新 |
| 随時 | 索引の `relatedSiteId` 紐づけを増やす（現在 187/211） |

> **リンク切れ点検の注意**：出典URLは中国・台湾のサイトが多く、実行環境によっては到達できない場合があります。開けないからといってすぐ削除せず、別の環境やブラウザでも確認してください。
