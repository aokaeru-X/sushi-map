# 02. データ仕様

編集作業のほとんどはこのドキュメントの範囲で完結します。**JSONを直すだけで画面が変わります。**

## 0. 編集前の心得

- JSONは**カンマ・波括弧の対応が1つでも崩れるとサイト全体が表示されなくなります**。編集後は必ず [構文チェック](#5-編集後の確認手順) を実行してください。
- 文字コードは **UTF-8**。日本語・簡体字・繁体字が混在します。
- インデントは**半角スペース2つ**。既存の書式に合わせてください。
- **推測で書かない。** 分からない項目は「公式サイトで要確認」と明記するのが、間違った情報を載せるより誠実です。

## 1. `data/calligraphy-sites.json` — 史跡・博物館データ（中核）

### 1.1 全体構造

```json
{
  "meta":    { ... },        // データ全体の説明
  "sites":   [ {...}, ... ], // 史跡・博物館 55件
  "columns": [ {...} ]       // コラム 1件
}
```

### 1.2 `sites[]` のフィールド一覧

**★＝必須**（55件すべてに入っています）

| フィールド | 型 | ★ | 説明 | 例 |
| --- | --- | :-: | --- | --- |
| `id` | string | ★ | 一意のID。`s01`〜`s55`。**索引からの参照キーなので絶対に変えない** | `"s01"` |
| `number` | number | ★ | 画面に出す通し番号。書籍の番号と一致 | `1` |
| `category` | string | ★ | 6種のいずれか（[1.3](#13-category-に使える値)） | `"重要史跡"` |
| `name` | string | ★ | 日本語名 | `"殷墟（殷墟宮殿宗廟遺址・王陵遺址）"` |
| `reading` | string | ★ | ひらがなの読み | `"いんきょ"` |
| `province` | string | ★ | 省・直轄市・自治区 | `"河南省"` |
| `city` | string | ★ | 市・県・区 | `"安陽市"` |
| `lat` | number | ★ | 緯度（小数点以下3〜4桁） | `36.122` |
| `lng` | number | ★ | 経度 | `114.325` |
| `era` | string | ★ | 時代区分 | `"殷（商）後期、前14〜前11世紀"` |
| `summary` | string | ★ | 要約1〜2文（80字程度）。詳細パネルで太字表示 | |
| `details` | string | ★ | 詳細解説。**書道史・金石学上の意義が中心**。400〜700字 | |
| `travel` | object | ★ | 旅行情報（[1.4](#14-travel-オブジェクト)） | |
| `highlights` | string[] | ★ | 現地の見どころ 2〜6個 | `["甲骨文出土地（YH127甲骨窖穴）", ...]` |
| `relatedWorks` | string[] | ★ | 関連する書跡名。**索引の項目名と一致させると連携が効く** | `["甲骨文（殷墟卜辞）"]` |
| `sources` | object[] | ★ | 出典（[1.5](#15-sources-配列)）。最低2件 | |
| `bookPage` | number | ★ | 参考書籍の該当ページ | `10` |
| `nameZh` | string | ★ | **簡体字**の名称 | `"殷墟"` |
| `addressZh` | string | ★ | **簡体字**の住所。現地で見せる用 | `"河南省安阳市殷都区殷墟路1号"` |
| `nameZhTw` | string | ★ | **繁体字**の名称 | `"殷墟"` |
| `addressZhTw` | string | ★ | **繁体字**の住所 | `"河南省安陽市殷都區殷墟路1號"` |
| `region` | string | ★ | `"CN"`（大陸）／`"TW"`（台湾）。表記の自動切替に使う | `"CN"` |
| `japanContext` | string | ★ | 日本との関わり・日本での受容 | |
| `latestFindings` | string | ★ | 最新の知見・現状 | |
| `digitalResources` | object[] | ★ | 中国のデジタルアーカイブ（[1.6](#16-digitalresources-配列)） | |
| `extraLocations` | object[] | | 離れた関連地点（[1.7](#17-extralocations-配列)）。3件のみ | |

### 1.3 `category` に使える値

この6つ以外を書くと、**そのピンは地図に出ません**（フィルタが効かないため）。

```
重要史跡 / 三大石窟 / 見逃せない史跡 / 六大博物院 / 十大博物館 / 特色ある博物館
```

追加したい場合は `js/calligraphy.js` 冒頭の `CATEGORY_COLORS` と `CATEGORY_ORDER` にも追記が必要です。

### 1.4 `travel` オブジェクト

```json
"travel": {
  "access":    "安陽東駅（高鉄）からタクシーで約20分、または路線バスで…",
  "hours":     "8:00-18:00（夏季）／8:00-17:30（冬季）を目安に、公式サイトで要確認",
  "admission": "共通70元前後（時期により変動）、公式サイトで要確認",
  "tips":      "宮殿宗廟遺址と王陵遺址は車で約10分離れているため…"
}
```

| キー | 書くこと |
| --- | --- |
| `access` | **最寄りの空港・鉄道駅からの具体的な行き方。** 所要時間とバス番号まで書く |
| `hours` | 開館時間。季節変動があれば併記。**不明なら「公式サイトで要確認」** |
| `admission` | 入場料の目安。**予約制ならその旨を必ず書く**（中国の博物館は実名予約制が多い） |
| `tips` | 個人旅行者向けの実務アドバイス。所要時間、混雑対策、周辺で合わせて回るべき場所、注意点 |

> **重要**：開館時間・料金は変動します。「〜前後」「要確認」と幅を持たせ、断定を避けてください。

### 1.5 `sources` 配列

```json
"sources": [
  { "title": "Yin Xu - UNESCO World Heritage Centre",
    "url": "https://whc.unesco.org/en/list/1114/",
    "publisher": "UNESCO World Heritage Centre" }
]
```

- **各項目に最低2件。** 公式サイト＋第三者情報源の組み合わせが望ましい
- **実在するURLのみ。** 実際に開いて内容を確認したものだけを入れてください

### 1.6 `digitalResources` 配列

中国国内のデジタルアーカイブへのリンクです。現地で近寄れない碑面を渡航前に読み込むためのものです。

```json
{ "title": "殷契文淵 甲骨文大数据平台",
  "url": "http://jgw.aynu.edu.cn/",
  "publisher": "安陽師範学院 甲骨文情報処理教育部重点実験室",
  "kind": "甲骨文データベース",
  "note": "2019年から全世界に無料公開。甲骨文著作152部・画像23万余点を収録" }
```

`kind` は画面上でバッジ表示されます（例：`文物データベース` `石窟デジタルアーカイブ` `簡牘データベース`）。

**よく使う連結先：**

| 資料の種類 | 連結先 | URL |
| --- | --- | --- |
| 碑帖・法書全般 | 中華珍宝館 | https://g2.ltfc.net/ |
| 甲骨文 | 殷契文淵 | http://jgw.aynu.edu.cn/ |
| 簡牘 | 簡牘学術資源数据共享平台 | https://jdsjk.nwnu.edu.cn/ |
| 敦煌写経 | 数字敦煌／数字蔵経洞 | https://www.e-dunhuang.com/ ／ https://cave17.e-dunhuang.com |
| 北京故宮の所蔵 | 故宮博物院 数字文物庫 | https://digicol.dpm.org.cn/ |

### 1.7 `extraLocations` 配列

**1つの項目でも訪問地が物理的に離れている**場合に使います。地図に破線円の副ピンが立ちます。

```json
"extraLocations": [
  { "label": "王羲之故居（生地・山東省臨沂）",
    "lat": 35.0653, "lng": 118.3482,
    "province": "山東省", "city": "臨沂市蘭山区",
    "nameZh": "王羲之故居",   "addressZh": "山东省临沂市兰山区洗砚池街20号",
    "nameZhTw": "王羲之故居", "addressZhTw": "山東省臨沂市蘭山區洗硯池街20號",
    "note": "紹興の蘭亭からは遠く離れるため、別日程での訪問が必要。" }
]
```

現在の3件：王羲之故居の臨沂（s06）／爨龍顔碑の陸良県（s07）／嶧山刻石（s25）。

### 1.8 `columns[]`（コラム）

地図に「欄」ピンで表示される参考情報です。`sites` より軽い構造で、`type: "column"`、`title`、`note`（100〜200字）を持ちます。現在1件（九成宮醴泉銘）。

## 2. `data/calligraphy-index.json` — 名跡・人名索引

```json
{
  "note": "データ全体の説明",
  "rows": [
    { "row": "あ行",
      "items": [
        { "name": "伊闕仏龕碑", "relatedSiteId": "s15" },
        { "name": "伊秉綬" }
      ] }
  ]
}
```

| フィールド | 必須 | 説明 |
| --- | :-: | --- |
| `row` | ★ | 行の見出し。あ／か／さ／た／は／ま／や／ら＋「補遺（本サイト収録史跡の関連書跡）」 |
| `items[].name` | ★ | 書跡・碑刻・人名 |
| `items[].relatedSiteId` | | 対応する史跡の `id`。**入れると画面に史跡名が出てクリックで飛べる** |
| `items[].source` | | `"site"` なら補遺（サイト由来）項目 |

- **書籍のページ番号は入れません**（→ [04-実装記録](04-実装記録.md#5-公開にあたっての判断)）
- `relatedSiteId` を増やすほど索引の価値が上がります。現在 187/211（89%）

## 3. `data/npm-collection.json` — 台北故宮 Open Data

**手で編集しないでください。`scripts/fetch-npm-opendata.mjs` が生成します**（→ [03-運用マニュアル](03-運用マニュアル.md#4-台北故宮-open-data-を更新する)）。

`items[].provenance` が取得元を示します：

| 値 | 意味 | 画面表示 |
| --- | --- | --- |
| `api` | 故宮OpenAPIから取得 | 通常表示 |
| `dataset` | ダウンロードしたデータセットから照合 | 通常表示 |
| `manual` | 未照合（参照リンクのみ） | 「Open Data未照合」と明示 |

このファイルが**無くても・壊れていてもサイトは動きます**（故宮の所蔵品欄が出なくなるだけ）。

## 4. よくある編集作業

### 4.1 史跡を1件追加する

1. `data/calligraphy-sites.json` の `sites` 配列に、[1.2](#12-sites-のフィールド一覧)の★フィールドをすべて埋めたオブジェクトを追加
2. `id` は既存と重複しない値（`s56` など）
3. `number` は表示順を決める。既存の番号を変える場合は他項目との整合に注意
4. 緯度経度は地図アプリで実際の地点を調べる。特定できない場合は市の中心座標で代用し、その旨を `travel.tips` に明記
5. [構文チェック](#5-編集後の確認手順)を実行 → ブラウザで確認

### 4.2 開館時間・料金を更新する

該当項目の `travel.hours` / `travel.admission` を書き換えます。あわせて、大きな変更（新館開放など）は `latestFindings` にも反映すると親切です。

> 実例：西安碑林博物館は2025年5月に新館が全面開放され、入場料が10元→85元に改定されました。このときは `travel.admission`・`travel.hours`・`travel.tips`・`latestFindings` の4か所を更新しています。

### 4.3 索引項目を史跡に紐づける

`data/calligraphy-index.json` の該当項目に `"relatedSiteId": "sXX"` を足すだけです。画面右側に史跡名が出て、クリックで地図が飛ぶようになります。

## 5. 編集後の確認手順

**この3つを必ず実行してください。**

```bash
# ① JSON構文チェック（エラーが出たら直すまで先に進まない）
python3 -m json.tool data/calligraphy-sites.json > /dev/null && echo "sites OK"
python3 -m json.tool data/calligraphy-index.json > /dev/null && echo "index OK"

# ② 件数と必須フィールドの点検
python3 - << 'PY'
import json
d = json.load(open('data/calligraphy-sites.json', encoding='utf-8'))
req = ['id','number','category','name','reading','province','city','lat','lng',
       'era','summary','details','travel','highlights','relatedWorks','sources',
       'nameZh','addressZh','nameZhTw','addressZhTw','region','digitalResources']
CATS = {"重要史跡","三大石窟","見逃せない史跡","六大博物院","十大博物館","特色ある博物館"}
ng = []
for s in d['sites']:
    for r in req:
        if not s.get(r): ng.append((s.get('id'), f'{r} が空'))
    if s.get('category') not in CATS: ng.append((s.get('id'), 'category が規定外'))
    if not (17 <= s.get('lat',0) <= 54 and 73 <= s.get('lng',0) <= 135):
        ng.append((s.get('id'), '座標が中国域外'))
ids = [s['id'] for s in d['sites']]
if len(ids) != len(set(ids)): ng.append(('-', 'id が重複'))
print(f"件数: {len(d['sites'])}")
print("問題なし" if not ng else f"要修正: {ng}")
PY

# ③ 索引の参照先が実在するか
python3 - << 'PY'
import json
s = {x['id'] for x in json.load(open('data/calligraphy-sites.json', encoding='utf-8'))['sites']}
i = json.load(open('data/calligraphy-index.json', encoding='utf-8'))
bad = [it['name'] for r in i['rows'] for it in r['items']
       if it.get('relatedSiteId') and it['relatedSiteId'] not in s]
print("索引の参照先: 問題なし" if not bad else f"存在しないIDを参照: {bad}")
PY
```

そのあとブラウザで実際に開いて、**追加した項目のピンが地図に出ること**と**詳細パネルが正しく表示されること**を目で確認してください。
