# 01. 仕様書

## 1. このサイトの目的

日本語話者の旅行者が、**中国の書道史跡・碑刻・博物館を自分で調べて自分で回れる**ようにするためのガイドサイトです。

書籍の巻頭「中国全図」に載る55件の史跡・博物館を土台に、各地点の位置・見どころ・行き方・現地事情・関連資料を1か所に集約しています。

### 想定する3つの旅のスタイル

企画時に、旅行のしかたを3つに整理しました。サイトはこの区分を前提に情報を載せています。

| | スタイル | 本サイトの位置づけ |
| --- | --- | --- |
| ① | ツアー参加型（旅行会社の企画に参加） | 訪問先の下調べに使える |
| ② | 有志団体型（仲間を募り訪問都市を相談して決める） | 行き先候補の選定と比較に使える |
| ③ | **個人手配型（航空券・宿を自分で手配して単独で回る）** | **主眼。アクセス・開館時間・中国語住所など実務情報を厚く載せている** |

③を主眼に置いたため、「行きたい」だけでなく「実際にたどり着ける」ための情報（現地で見せる中国語住所、予約要否、所要時間、周辺の合わせて回るべき場所）を各項目に持たせています。

## 2. ページ構成

| URL | ファイル | 内容 |
| --- | --- | --- |
| `/` | `index.html` | **書の旅 — 中国書道史跡ガイド**（本体・55件） |
| `/sushi.html` | `sushi.html` | 蘇軾（蘇東坡）足跡地図（16地点・別企画） |

両ページはヘッダー右上のリンクで相互に行き来できます。データ・スクリプトは独立していて、互いに影響しません。

### 3.1 地図

- **番号付きピン**：全55件を配置。番号は書籍の通し番号と一致します。
- **カテゴリ別の色**：

  | カテゴリ | 色 | 件数 |
  | --- | --- | --- |
  | 重要史跡 | `#a3372b`（赤茶） | 13 |
  | 三大石窟 | `#7d5ba6`（紫） | 3 |
  | 見逃せない史跡 | `#b8863b`（金茶） | 11 |
  | 六大博物院 | `#2e6e8e`（青） | 6 |
  | 十大博物館 | `#3a6b5c`（緑） | 10 |
  | 特色ある博物館 | `#6b6b6b`（灰） | 12 |

- **副ピン（破線の円）**：1つの項目でも訪問地が離れている場合に立てます。現在3件（王羲之故居の臨沂／爨龍顔碑の陸良県／嶧山刻石）。
- **コラムピン（「欄」）**：地図上の参考情報。現在1件（九成宮醴泉銘）。
- **ピンの重なり回避**：近接地点は自動で少しずらして描画します（西安・洛陽など密集地対策）。

### 3.2 サイドバー（地図タブ）

| 機能 | 挙動 |
| --- | --- |
| 検索 | 名称・読み・省・市を対象に部分一致で即時絞り込み |
| カテゴリ絞込 | チップをクリックで表示/非表示をトグル。地図と一覧の両方に反映 |
| 中国語表記切替 | 「自動／簡体字／繁体字」。**自動**＝大陸は簡体字・台湾は繁体字 |
| 一覧 | カテゴリごとに見出しを付けて番号順に表示。クリックで地図が移動し詳細パネルが開く |

### 3.3 詳細パネル

項目をクリックすると開きます。上から順に：

1. **カテゴリバッジ・番号・名称・読み**
2. **所在地・時代**
3. **現地で見せる中国語住所** — 名称と住所を中国語で表示。「コピー」ボタンでクリップボードへ。タクシー運転手に見せる／百度地図・高德地図に貼り付ける用途
4. **要約**（1〜2文）と**詳細解説**（400〜700字。書道史・金石学上の意義が中心）
5. **旅行情報** — アクセス／開館時間／入場料／旅のヒント
6. **見どころ**（箇条書き）
7. **離れた場所にある関連地点**（該当項目のみ。中国語住所付き）
8. **國立故宮博物院 Open Data 所蔵品**（台北故宮のみ）
9. **中国のデジタルアーカイブ** — 現地の公式データベースへのリンク
10. **日本との関わり・日本での受容** — 日本の書道教育での位置づけ、日本国内の関連所蔵品、日中交流史
11. **最新の知見・現状** — 近年の発掘成果・研究動向・施設更新
12. **関連する書跡・碑刻** — チップ。クリックすると索引タブへ移動して検索
13. **出典・参考情報** — 外部リンク
14. **参考書籍 該当ページ**

### 3.4 名跡・人名索引タブ

**「作品名から、それを実見できる現地の史跡を引く」**ための索引です。

- 計 **211項目**（うち **187項目（約89%）** が地図上の史跡へリンク）
- 行ごと（あ・か・さ・た・は・ま・や・ら＋補遺）に一覧表示
- 右側に対応する史跡の番号と名称を表示。クリックで地図タブへ切り替わり、該当地へ移動
- 検索ボックスで絞り込み可

例：「蘭亭序」→ 6. 王義之故居と蘭亭 ／「元景造像記」→ 24. 万仏堂石窟

> **書籍のページ番号は収録していません。** 索引項目とページ番号の対応そのものが書籍の編集成果にあたるため、公開にあたって削除しました（→ [04-実装記録](04-実装記録.md#5-公開にあたっての判断)）。

## 4. 技術構成

### 4.1 使っているもの・使っていないもの

| | 内容 |
| --- | --- |

### 4.2 ファイル構成

```
sushi-map/
├── index.html                     ← 書の旅（トップページ）
├── sushi.html                     ← 蘇軾足跡地図
├── css/
│   ├── style.css                  ← 両ページ共通のベース
│   └── calligraphy.css            ← 書の旅の固有スタイル
├── js/
│   ├── calligraphy.js             ← 書の旅のロジック（約590行）
│   └── app.js                     ← 蘇軾足跡地図のロジック
├── data/
│   ├── calligraphy-sites.json     ← 【中核】55件の史跡・博物館データ（260KB）
│   ├── calligraphy-index.json     ← 名跡・人名索引（211項目）
│   ├── npm-collection.json        ← 台北故宮 Open Data（自動生成物）
│   └── sushi.json                 ← 蘇軾足跡地図のデータ
├── scripts/
│   └── fetch-npm-opendata.mjs     ← 台北故宮 Open Data 取込スクリプト
├── vendor/leaflet/                ← Leaflet.js 本体（同梱）
├── docs/                          ← このドキュメント
├── .env.example                   ← APIキー設定のテンプレート

```

**編集頻度が高いのは `data/` の2ファイル**です。HTML/CSS/JSは機能を変えるとき以外は触りません。

### 4.3 データの流れ

```
data/calligraphy-sites.json ─┐
data/calligraphy-index.json ─┼→ js/calligraphy.js が fetch → 画面を組み立て
data/npm-collection.json ────┘   （npm-collection.json は任意。無くても動く）
                                          ↑
                          scripts/fetch-npm-opendata.mjs が生成
                          （手元で実行。ブラウザからは呼ばない）
```

ポイントは**ブラウザが外部APIを直接呼ばない**ことです。台北故宮APIとの通信はビルド時スクリプトに閉じ込め、サイトは生成済みの静的JSONだけを読みます（理由 → [04-実装記録](04-実装記録.md#4-apiキーをクライアントに置かない設計)）。

### 4.4 js/calligraphy.js の主な関数

全体が1つの即時実行関数（IIFE）で包まれており、グローバル変数を汚しません。

| 関数 | 役割 |
| --- | --- |
| `renderMarkers()` | 地図上のピンを描画（本ピン・副ピン・コラムピン） |
| `renderSiteList(filter)` | サイドバーの一覧を描画 |
| `renderSiteDetail(item)` | 詳細パネルを組み立て |
| `renderIndexList(filter)` | 索引タブを描画 |
| `zhBlockHtml(o)` | 中国語住所ブロックを生成（簡繁の出し分けを含む） |
| `resolveScript(region)` | 表記設定と地域から簡体字/繁体字を決定 |
| `digitalResourcesHtml(list)` | デジタルアーカイブ欄を生成 |
| `npmCollectionHtml(siteId)` | 台北故宮 Open Data 欄を生成 |
| `jitteredLatLng(lat, lng, seen)` | 近接ピンの重なりをずらす |
| `focusSite(item)` | 地図を該当地へ移動し詳細を開く |
| `escapeHtml(str)` | **HTMLエスケープ。データを画面に出す箇所では必ず通すこと** |

### 4.5 セキュリティ上の約束

1. **画面に出すデータは必ず `escapeHtml()` を通す。** JSONは人手で編集するため、意図しないHTMLが混ざる余地を残さないためです。
2. **APIキーをクライアント側のJS・HTML・JSONに書かない。** リポジトリは公開されているため、書いた瞬間に露出します。
3. **`.env` と `*.key` はコミットしない。** `.gitignore` 済みですが、`git add -A` の前に `git status` を確認する習慣をつけてください。

## 5. 対応環境

- モダンブラウザ（Chrome / Firefox / Safari / Edge の現行版）
- **地図タイルの表示にインターネット接続が必要**です（OpenStreetMapから取得するため）。ページ本体・データ・Leafletはすべて同梱なので、地図の背景以外はオフラインでも動きます。
- スマートフォン対応：画面幅860px以下でサイドバーが開閉式に切り替わります（現地でスマホから使うことを想定）。
