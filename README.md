# 中国書道史跡マップ集

中国の書道史・金石学にまつわる史跡・博物館を扱うインタラクティブな静的Webサイト集です。ビルド不要、Leaflet.js をローカル同梱しているため CDN 非依存で動作します。

1. **蘇軾（蘇東坡）足跡地図**（`index.html`） — 北宋の文学者・政治家 蘇軾（1037–1101）の生涯の赴任・左遷の地を年代順にマッピング
2. **書の旅 — 中国書道史跡ガイド**（`calligraphy.html`） — 中国全土の重要史跡・三大石窟・見逃せない史跡・六大博物院・十大博物館・特色ある博物館（計55件）と、名跡・人名索引を網羅した旅行ガイド

## 見る

```
python3 -m http.server 8000
# http://localhost:8000/index.html        （蘇軾足跡地図）
# http://localhost:8000/calligraphy.html  （書の旅）
```

GitHub Pages などで公開する場合もそのまま配置するだけで動作します。地図タイルは OpenStreetMap を使用しているため、閲覧環境にインターネット接続が必要です。

## 構成

- `index.html` / `js/app.js` / `data/sushi.json` — 蘇軾足跡地図（生涯データ、時期・地名・出来事・代表作・現存の記念地）
- `calligraphy.html` / `js/calligraphy.js` / `css/calligraphy.css` — 書の旅（史跡・博物館データの地図表示、カテゴリ別フィルタ、検索、名跡索引とのクロスリンク）
- `data/calligraphy-sites.json` — 55件の史跡・博物館データ（所在地・時代・詳細解説・アクセス等の旅行情報・出典）
- `data/calligraphy-index.json` — 名跡・人名索引（判読できた分の部分データ）
- `css/style.css` — 両サイト共通のベーススタイル
- `vendor/leaflet/` — Leaflet.js をローカルに同梱（CDN非依存、オフラインでも動作）

## 蘇軾足跡地図の機能

- 誕生（1036年）から死去（1101年、常州）までの16地点を番号付きピンで時系列表示し、破線で経路を結んでいます。
- 左側の年表から地点をクリックすると地図が該当地に移動し、右側パネルにその地での出来事・代表作（〈赤壁賦〉〈水調歌頭〉〈寒食帖〉など）が表示されます。
- 「現存する記念地・史跡」レイヤー（任意表示）で、儋州の東坡書院、常州蘇東坡紀念館、恵州の東坡亭など、現在も訪れられる史跡を確認できます。

`data/sushi.json` は提供された `sushi_map_data.csv`（生涯15項目＋書跡9項目）をもとに、蘇軾研究で広く知られる史実（烏台詩案の投獄地、儋州での講学・著作、恵州での朝雲の死など）を補足して構成しています。年代・地名は資料により表記ゆれがあるため、一部（北帰時の渡海地点など）は推定であることを地図上の注記で明示しています。

## 書の旅（中国書道史跡ガイド）の機能

日本と中国の鑑定番組にも通じる「書」への関心を出発点に、単独旅行者が自ら計画を立てて中国の書道史跡・博物館を巡れるようにまとめたガイドです。ツアー参加型・有志団体型にも対応できる情報構成にしつつ、個人手配型の旅行を主眼にしています。

- 55件の史跡・博物館を6カテゴリ（重要史跡／三大石窟／見逃せない史跡／六大博物院／十大博物館／特色ある博物館）に分けてカテゴリ色付きピンで地図表示。カテゴリチップでの絞り込み、名称・地名でのインクリメンタル検索に対応。
- 各エントリの詳細パネルには、所在地・時代・書道史上の意義の解説、アクセス／開館時間／入場料／旅のヒントといった実用的な渡航情報、見どころ、関連する書跡・碑刻、出典（実在URL）を掲載。
- 「名跡・人名索引」タブでは、書跡・碑刻・人名を行（あ・か・さ・た・は・ま・や・ら）ごとに一覧表示し、検索・関連史跡へのクロスリンクが可能。
- 各詳細パネルには中国語の名称・住所を掲載。現地でタクシー運転手に見せたり、百度地図・高德地図など中国の地図アプリに貼り付けて検索したりできるよう、ワンクリックでコピーできるボタン付き。
- **簡体字／繁体字の切替**に対応（`nameZh` / `addressZh` と `nameZhTw` / `addressZhTw`）。既定の「自動」では、大陸の史跡に簡体字、台湾所在の2件（台北・国立故宮博物院／中央研究院歴史語言研究所）に繁体字を表示する。全件を簡体字・繁体字のいずれかに固定することもできる。
- 各エントリに**「日本との関わり・日本での受容」**（日本の書道教育での位置づけ、日本国内の関連所蔵品、日中交流史）と**「最新の知見・現状」**（近年の発掘成果・研究動向・施設更新）を掲載。

### データについて（重要な注意点）

- **史跡・博物館データ（`data/calligraphy-sites.json`）**: 元となる書籍の目次（55件）をもとに、各項目を個別にWeb調査して作成しました。所在地座標・開館時間・入場料・予約要否などは変動するため、**訪問前に必ず各施設の公式サイト等で最新情報を確認してください**。一部の座標は現地の正確な地点が特定できず、行政中心地等からの近似値を用いている箇所があります（該当箇所は本文中に注記）。
- **名跡・人名索引（`data/calligraphy-index.json`）**: 元書籍の索引ページを撮影・判読した部分データ（151項目）に加え、本サイト収録55件の史跡・博物館で実見できる主要書跡を「補遺」として60項目追加し、計211項目を収録。うち187項目（約89%）が地図上の該当史跡へクロスリンクします。なお元書籍の索引のうち、な行の一部・ぬ〜の行・わ行は写真が未提供のため未収録です（該当ページの写真が得られ次第、追加可能）。補遺項目は原本の索引に由来しないため、ページ番号の代わりに対応する史跡名を表示します。
