# 蘇軾（蘇東坡）足跡地図

北宋の文学者・政治家 蘇軾（1037–1101）が生涯に赴任・左遷された地を年代順に地図上へマッピングし、各地での出来事と代表作を紹介するインタラクティブな静的Webページです。

## 見る

`index.html` をブラウザで開くか、GitHub Pages などで公開してください。ビルド不要の静的サイトです。

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 構成

- `index.html` — ページ本体
- `css/style.css` — スタイル
- `js/app.js` — 地図初期化・タイムライン描画・詳細パネルのロジック（Leaflet使用）
- `data/sushi.json` — 蘇軾の生涯データ（時期・地名・出来事・代表作・現存の記念地）
- `vendor/leaflet/` — Leaflet.js をローカルに同梱（CDN非依存、オフラインでも動作）

## 機能

- 誕生（1036年）から死去（1101年、常州）までの16地点を番号付きピンで時系列表示し、破線で経路を結んでいます。
- 左側の年表から地点をクリックすると地図が該当地に移動し、右側パネルにその地での出来事・代表作（〈赤壁賦〉〈水調歌頭〉〈寒食帖〉など）が表示されます。
- 「現存する記念地・史跡」レイヤー（任意表示）で、儋州の東坡書院、常州蘇東坡紀念館、恵州の東坡亭など、現在も訪れられる史跡を確認できます。
- 地図タイルは OpenStreetMap を使用しているため、閲覧環境にインターネット接続が必要です（ページ自体・データ・地図ライブラリはすべてローカル同梱で動作します）。

## データについて

`data/sushi.json` は提供された `sushi_map_data.csv`（生涯15項目＋書跡9項目）をもとに、蘇軾研究で広く知られる史実（烏台詩案の投獄地、儋州での講学・著作、恵州での朝雲の死など）を補足して構成しています。年代・地名は資料により表記ゆれがあるため、一部（北帰時の渡海地点など）は推定であることを地図上の注記で明示しています。
